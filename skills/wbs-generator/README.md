# wbs-generator — WBS(작업분해구조) 엑셀 생성 스킬

프로젝트 설명이나 작업 목록을 넣으면 L1~L3 작업 계층 · 일정 · 담당자를 제안 · 확정해 진척률 · 간트차트 · 공휴일까지 자동 계산되는 WBS 엑셀이 나오는 스킬

## 진행 단계

```
① 시작 인터뷰(8문항) → ② 참고 자료 확인 → ③ L2 제안 → ④ L3 제안 → ⑤ 일정 · 담당자 → ⑥ 최종 트리 확인(GATE) → ⑦ 엑셀 생성 · 안내
```

| <div align="center"><sub>단계</sub></div> | <sub>하는 일</sub> | <sub>사용자 할 일</sub> | <sub>결과물</sub> |
|:---|:---:|:---:|:---:|
| <sub>① 시작 인터뷰</sub> | <sub>아래 8문항을 하나씩 질문 · 모르면 제안 · 기본값 제시</sub> | <sub>답변</sub> | <sub>프로젝트 정보</sub> |
| <sub>② 참고 자료 확인</sub> | <sub>첨부 · 붙여넣은 기획서 · 일정 메모를 먼저 읽고 초안에 반영(없으면 개요만으로 분해)</sub> | <sub>(선택) 자료 첨부</sub> | <sub>반영 메모</sub> |
| <sub>③ L2 제안</sub> | <sub>고른 L1마다 중분류(L2) 초안 표 · L3 · 일정은 이 단계에서 미질문</sub> | <sub>추가 · 삭제 · 수정 · 확정</sub> | <sub>L2 목록</sub> |
| <sub>④ L3 제안</sub> | <sub>L2마다 세부작업(L3) 초안 · 상세 수준 「L2까지」면 생략 · 「대분류만」이면 ③ · ④ 모두 생략</sub> | <sub>추가 · 삭제 · 수정 · 확정</sub> | <sub>L3 목록</sub> |
| <sub>⑤ 일정 · 담당자</sub> | <sub>말단 작업에 시작/종료일 · 담당자(필요 시 진척율) 제안 · 상위(L1 · L2)는 자동 계산</sub> | <sub>수정</sub> | <sub>일정표</sub> |
| <sub>**⑥ 최종 트리 확인 (GATE)**</sub> | <sub>생성 직전 전체 트리를 표로 재제시 · 임의 확정 금지</sub> | <sub>**전체 트리 · 일정 최종 확인** (「알아서 해줘」로 넘긴 단계가 있으면 필수)</sub> | <sub>확정 트리</sub> |
| <sub>⑦ 엑셀 생성 · 안내</sub> | <sub>JSON → `build_wbs.py` + 템플릿 · 생성 경로와 「엑셀에서 열면 진척률 · 간트차트 · 공휴일 자동 표시」 안내</sub> | <sub>엑셀 확인</sub> | <sub>`프로젝트명_WBS_YYYYMMDD.xlsx`</sub> |

## 산출물

엑셀 시트 6개 (표지 → 사용안내 → 개정이력 → 요약 → WBS → 공휴일)

| <div align="center"><sub>시트</sub></div> | <sub>내용</sub> |
|:---|:---:|
| <sub>표지</sub> | <sub>프로젝트명 · 기간 · 작성자 · 버전</sub> |
| <sub>사용안내</sub> | <sub>파일 보는 법 · 수정법(온보딩)</sub> |
| <sub>개정이력</sub> | <sub>버전 · 날짜 · 작성자 · 변경 내용(최초 작성 행 자동)</sub> |
| <sub>요약</sub> | <sub>전체 + 단계(L1)별 기간 · 목표진척율 · 진척율 · 상태(WBS와 수식 연결)</sub> |
| <sub>WBS</sub> | <sub>작업표(No · L1~L3 · 담당자 · 산출물 · 일정 · 진척률 · 상태 · 비고) + 자동 간트차트</sub> |
| <sub>공휴일</sub> | <sub>프로젝트 기간 내 대한민국 공휴일 자동 목록(날짜 · 명칭)</sub> |

- WBS 시트 컬럼: No(A~C, 레벨별 한 칸) · L1 · L2 · L3 · 필요자료 · 마감기한 · 수행사(기본 비표시) · 담당자 · 산출물 · 시작일 · 종료일 · 진행일 · 총/목표/실 작업량 · 목표진척율 · 진척율 · 상태 · 비고 · 달력(V열~)

## 작동 규칙

대부분 자동이라 몰라도 사용 가능 · 참고용 정리

### 작업 레벨과 No

- **L1**(대분류) → **L2**(중분류) → **L3**(작업, 말단) 3단계 · L4 미지원
- L1은 **8개 고정**: `프로젝트 관리` `기획` `디자인` `퍼블리싱` `개발` `테스트` `오픈` `안정화` (해당 단계만 사용)
- No 자동(3칸, 각 자릿수가 레벨) — 예) 기획 = `100`, 요구사항분석 = `110`, 수집 = `111`
- 행 색: L1 = 짙은 회색(흰 글씨) · L2 = 연노랑 · L3 = 흰색 · 전체 작업 행 최대 60개

### 사용자 입력 vs 자동

| <div align="center"><sub>레벨</sub></div> | <sub>직접 입력</sub> | <sub>자동 계산</sub> |
|:---|:---:|:---:|
| <sub>L3(말단)</sub> | <sub>시작일 · 종료일 · 진척율 · 상태</sub> | <sub>진행일 · 작업량 · 목표진척율</sub> |
| <sub>L1 · L2</sub> | <sub>이름 · 상태만(선택 담당자)</sub> | <sub>작업량 · 진척율 전부</sub> |

- **진행일** = `NETWORKDAYS(시작일, 종료일, 공휴일)` — 시작~종료 사이 평일 수(공휴일 제외)
- **총작업량** = L3는 진행일, L2는 하위 L3 합, L1은 하위 L2 합
- **목표작업량** = 총작업량 × 기준일 위치 가중치(기준일 < 시작 = 0 · 기준일 ≥ 종료 = 1 · 그 사이 = 경과 영업일 비율)
- **실작업량** = 총작업량 × 진척율(L3) · 상위는 하위 합
- **목표진척율** = 목표작업량 ÷ 총작업량
- **진척율** = L3는 직접 입력(0~1, %) · L1 · L2는 실 ÷ 총 자동

### 상태와 간트 색

- 상태(드롭다운): `대기` `진행중` `고객검토` `수정반영` `완료` `보류` · 비우면 진척율로 자동 추정
- 완료 = 초록 / 진행중 · 고객검토 · 수정반영 = 진척만큼 파랑 + 잔여 연파랑 / 대기 = 회청 / 보류 = 주황 · 주말 · 공휴일 색 표시

### 일정 · 기준일 · 공휴일 (자동)

- 시작일 · 종료일로 간트 막대 자동 생성 · 상위(L1 · L2) 기간은 자식들의 최소~최대로 자동 설정(직접 지정도 가능)
- 달력은 메타 시작일(M3) · 종료일(R3) 셀 참조 수식 → 시트에서 날짜를 바꾸면 달력 · 요일 · 월 · 간트 자동 재계산 · 종료일을 크게 늘리면 오른쪽 숨겨진 열 표시 필요(숨긴 열 범위는 생성 시점 기준 고정)
- 기준일(오늘 선) = 오늘 날짜 자동 · 간트에 세로선 표시
- 공휴일 = 대한민국 공휴일 자동 반영(음력 · 대체휴일 포함, 제헌절 제외) · 직접 지정도 가능

## 엑셀에서 직접 수정할 때

생성된 WBS는 대부분 수식 자동 계산 · 직접 손볼 때 참고

### 안전 — 입력 칸만 수정 (수식 유지)

- **일정 변경** — 해당 작업의 `시작일 · 종료일`만 변경 → 진행일 · 작업량 · 간트 자동 갱신
- **진행률 변경** — **말단(L3)** 작업의 `진척율` 칸에 % 입력(예 50%) · 상위 자동
- **상태 변경** — `상태` 칸 드롭다운 선택 → 간트 색 변경
- **전체 시작 · 종료일 변경** — 맨 위 메타의 시작일 · 종료일 셀 수정(달력 연동)

### 주의 — 작업(행)을 추가 · 삭제할 때

- 수식이 레벨마다 다르고 상위 작업이 특정 자식 칸을 더하는 구조 → 손이 필요한 작업
- **L3 추가** — 같은 레벨 행 복사 → 붙여넣기로 수식 유지 · 직접 넣을 것 = `시작일 · 종료일 · 진척율 · 상태`
- **상위(L1 · L2)의 `총작업량` · `실작업량` = 「자식 합」 수식**(예 `=O9+O10`) — 자식을 추가 · 삭제하면 합 수식에 새 행 포함하도록 수정(예 `=O9+O10+O11`)
- 행 **삭제** 시 엑셀이 참조를 자동 정리하지만 상위 합계 수식 한 번 재확인

### 레벨별 수식 요약

| <div align="center"><sub>칸</sub></div> | <sub>L3(말단)</sub> | <sub>L1 · L2(상위)</sub> |
|:---|:---:|:---:|
| <sub>총작업량</sub> | <sub>`=진행일`</sub> | <sub>자식들의 합</sub> |
| <sub>실작업량</sub> | <sub>`=총작업량 × 진척율`</sub> | <sub>자식들의 합</sub> |
| <sub>진척율</sub> | <sub>직접 입력(%)</sub> | <sub>`=실작업량 ÷ 총작업량`</sub> |
| <sub>진행일 · 목표작업량 · 목표진척율</sub> | <sub>모든 레벨 자동 수식 · 수정 불필요</sub> | <sub>모든 레벨 자동 수식 · 수정 불필요</sub> |

- 요약: **날짜 · 진척율 · 상태 변경은 자유**, **행을 추가 · 삭제할 때만** 상위 합계 수식 확인

## 설치 · 단독 사용

```bash
cp -r skills/wbs-generator ~/.claude/skills/wbs-generator
```

- 리포 루트 기준 명령 · 스킬 일괄 설치는 원본 리포 `bash install-global.sh` · 공유 리포 `share/update.sh`
- 의존성: Python 3 + `pip install openpyxl holidays` — `openpyxl` = 엑셀 생성 · `holidays` = 한국 공휴일 자동 계산(미설치 시 공휴일 빈 상태로 생성 + 경고)
- 실행은 Claude 담당(사용자 직접 입력 불필요) — `python scripts/build_wbs.py <입력.json> <출력.xlsx> template/WBS_template.xlsx` · Windows PowerShell은 `$env:PYTHONIOENCODING="utf-8"; $env:PYTHONUTF8="1"` 선행
- 템플릿 재생성: `python scripts/make_template.py <원본_WBS샘플.xlsx> template/WBS_template.xlsx`
- 하네스 안에서: 이 스킬을 호출하는 하네스 미지정 · `sync-skills`가 전체 스킬을 `agent/proposal` · `agent/feature-spec-sb` · `agent/test-runner`의 `.claude/skills/`로 복사하므로 그 폴더 세션에서도 사용 가능
