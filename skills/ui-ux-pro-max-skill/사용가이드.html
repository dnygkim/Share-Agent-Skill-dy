Python 확인

터미널 · Windows = python / Mac = python3
python --version
  • Python 3.x 표시 → 통과
  • 명령어 오류 → python.org에서 Python 3 설치 후 터미널 재시작 (Windows는 설치 첫 화면 「Add python.exe to PATH」 체크)
  • 설치는 사람이 직접 — 스킬은 대신 설치하지 않고 안내만

4단계별 진행

한 번에 다 만들지 않고, 디자인 시스템부터 정하는 순서

추천 세트를 먼저 확정 · 저장해 두면 화면이 늘어나도 컬러 · 서체 · 간격이 흔들리지 않는 구조

① 요청 ~ ⑤ 납품 전 점검

1요청 한 줄 보내기

  • §3 템플릿대로 입력 → 스킬 자동 실행 → 제품 유형 · 업종 · 분위기 · 스택 추출
  • 스택 미기재 시 package.json 등 프로젝트 파일로 자동 감지, 빈 폴더면 질문 또는 HTML + Tailwind
  • 추천만 먼저 보고 싶을 때 → 문장 끝 「디자인 시스템만 먼저 추천해줘」

3저장

  • 요청 「프로젝트 이름 OOO로 디자인 시스템 저장해줘」 → 프로젝트 폴더에 아래 두 파일 생성
  • design-system/<프로젝트>/MASTER.md — 전체 기준(컬러 · 서체 · 간격 · 컴포넌트)
  • design-system/<프로젝트>/pages/<화면>.md — 화면별 예외, 「대시보드 화면 규칙도 따로 저장」 요청 시

덮어쓰기 방지 같은 프로젝트의 MASTER.md가 이미 있으면 저장 생략 — 바꾸려면 「덮어써서 다시 저장해줘」 명시

4화면 구현

  • 요청 「MASTER.md 기준으로 [화면] 만들어줘」
  • 화면별 파일(pages/)이 있으면 그 규칙 우선, 없으면 MASTER.md 그대로
  • 스택별 가이드 22종 반영 — 예) Next.js = 서버 컴포넌트 · next/image 최적화, Flutter = 위젯 분리 · 상태 관리

5납품 전 점검

  • 요청 「납품 전 체크리스트로 점검해줘」 → 우선순위 순 점검
  • 1순위 접근성(대비 4.5:1 · alt 텍스트 · 키보드 이동) · 2순위 터치(터치 영역 44×44px · 로딩 피드백) · 3순위 성능(이미지 지연 로딩 · 레이아웃 이동(CLS))
  • 모바일 앱이면 앱 전용 점검(안전 영역 · 다크 모드 대비 · 터치 피드백) 추가
