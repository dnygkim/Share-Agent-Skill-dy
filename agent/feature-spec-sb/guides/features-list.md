# 기능 목록 (Feature List)

> **Owner** 황다혜 프로 · **Resource** https://github.com/starryetribe-droid/AX-Pilot/tree/main
> 원본 가이드의 기능 정의를 이 리포에서 오프라인으로 쓸 수 있게 옮긴 표다.
> 서버 토큰이 있으면 `fetch_guide.py`가 서버 최신본을 우선 사용한다.

기능 ID로 요청이 들어오면(`A-02 PRD 만들어줘`) 여기서 **기능명·설명·우선순위·카테고리 디렉토리**를 찾는다.
카테고리 뒤의 `` `슬러그` ``가 산출물 저장 경로다 — 예: `A-01` → `01. 공통 기능/01_auth_account/PRD/A-01_signup.md`.

우선순위: **P0 필수**(도메인 무관 거의 반드시) · **P1 권장**(MVP에서는 제외 가능) · **P2 선택**(서비스 성격에 따라)
