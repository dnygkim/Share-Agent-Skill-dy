## 1. 진단 · 이슈

- **원인 · 체감 · 영향 3열 행** — 열 머리 「주요 발생 요인 | 현업 체감 | 방지 시 영향」, 행 = 주제 3개(아이콘 · 주제 · 부제), 체감 칸은 라벨 + 현업 한 줄, 영향 칸 앞 화살표(→) · 하단 POINT · 현황 진단 · [R-0002]
- **딜레마 3장 묶음** — 개요 장(딜레마 3개 번호 카드) → 딜레마마다 「질문형 문제 장 → 원인 · 영향 장 → 고려사항 장」 · 같은 번호 원문자(①②③)로 이어 읽힘 · 사업 이해 · 리스크 · [R-0001]
- **안 · 밖 대비** — 왼쪽 INSIDE(내부 의존 · ↺ 반복 고리) / 오른쪽 OUTSIDE(외부 자극 · 리스크 표지) 두 판, 가운데 대비 · 매너리즘 · 외부 역량 필요 · [R-0001]

## 2. 전략 · 강점

- **이유 카드 4열** — 번호(01–04) · 두 글자 라벨 · 2줄 주장 · 이미지 자리 · 근거 2–3줄 · ✓ 핵심 포인트(수치) 순서로 같은 높이 4장 · 제안사 특장점 · [R-0002]
- **과업 카드 5열 → 상세 장** — 개요 장에서 영문 라벨 카드 5개(번호 · 분류) → 과업마다 상세 장 1장씩 같은 번호 머리 · 전략 → 과제 구조 · [R-0001]

## 3. 프로세스 · 흐름

- **재투입 순환 4단계** — 01 도구 투입 → 02 반복 공수 절감 → 03 남는 공수 → 04 고도화 재투입 ↺(처음으로 되돌아오는 화살표) · 효율화 · AX · [R-0001]
- **단계 소요 흐름** — STEP 1(소요 1일) → STEP 2(소요 3–5일) → STEP 3(반영) · 단계 상자 위에 소요 기간, 화살표 사이 산출물 · 처리 절차 · 패스트트랙 · [R-0001]
- **도구 체인 흐름** — 입력(회의 음성 등) → 도구 A → 도구 B → 산출물(초안) · 단계 이름 위 큰 % 단축률과 짝 · 직무별 AX 적용 · [R-0001]
- **퍼널 + 기능 매핑** — 유입 → 전환 → 활성화 3단 가로 퍼널, 각 단 아래 해당 신규 기능 번호(①②③) · 성장 전략 · [R-0001]

## 4. 비교 · 전환

- **등식형 전후** — 「BEFORE {기존 투입} vs AFTER {적용 후 절감} = {연간 합계}」 — 세 상자를 vs · = 기호로 잇고 결과 상자만 강조 · 효과 정량화 · [R-0001]
- **선택지 × 같은 항목 비교** — 선택지 N개(계좌 · 요금제 등)를 열로, 같은 평가 항목 3개(세금 · 비용 · 실질 결과)를 행으로 반복 · 마지막 행만 강조 · 기능 제안 · [R-0001]
- **전후 화면 짝** — BEFORE / AFTER 화면 두 장을 같은 크기로 좌우, 바뀐 곳 번호 표시 · 기능 제안 · [R-0001]

## 5. 일정 · 운영 체계

- **분기 반복 타임라인** — Q1 → Q2 → Q3 → Q4 각 칸에 같은 정례 활동(현장 감사 등)과 담당 역할 · 정례 거버넌스 · [R-0001]
- **병렬 트랙 캘린더** — TRACK 1 · 기술 / TRACK 2 · UX 두 줄에 Q1–Q4 표시, 오른쪽에 샘플 리포트 썸네일 · 품질 감사 체계 · [R-0001]
- **등급 사다리** — GRADE 1(전면 중단) · 2(주요 기능) · 3(일부 화면) 세로 3단, 단마다 조치 시간 목표(임시조치 · 근본복구) · 장애 대응 SOP · [R-0001]
- **역제안 사이클 흐름** — 월간 트렌드 → 데이터 → 역제안 리포트 → 채택 → 절감 공수 → 기능 구현, 6단 가로 흐름 · 이행 보증 · [R-0001]
