## 1. KPI · 큰 숫자

- **단위가 다른 KPI 3타일** — 타일 3개에 「{지표 이름} / 00개 · 00% · 00주 / 근거와 의미 2줄 이내」 — 단위를 서로 다르게(개수 · 비율 · 기간) 골라 규모 · 효과 · 속도를 함께 · 실행 방안 · 사업 개요 · [R-0002, R-0005, R-0007]
- **목표 하한 큰 숫자** — 「TARGET ≥{수치}%」 + 아래 무엇의 절감인지 한 줄 · 기호(≥)로 약속 범위 표시 · 효과 · 효율화 · [R-0001]
- **100% 보증 라벨** — 「{대상} 100%」 큰 숫자 + 영문 분류 라벨 + 한글 한 줄(무엇을 보증하는지) · 인력 · 연속성 · [R-0001]
- **출처 · 시점 붙인 회사 지표 타일** — 큰 숫자 + 단위, 바로 아래 「{기준 기관} · {기준 시점}」 한 줄(설립 · 인원 · 신용등급 · 평균 매출) · 회사 개요 · [R-0005]
- **총원 + 두 분류 묶음** — 「총 인력 {수치}명({기준 연월})」 큰 숫자, 아래 등급별 · 분야별 두 묶음(라벨 + 막대 · 인원), 비율 요약 한 줄(「고급 이상 00% 이상 · 실무 인력 00%」) · 조직 · 제안사 현황 · [R-0011, R-0012]
- **등급 큰 글자 + 평가기관 · 평가일** — 신용등급 문자를 크게(부호는 따로 작게), 옆에 평가기관 · 평가일 라벨 · 재무 · 신용 · [R-0011]
- **3개년 + 평균 열 재무표** — 열 = 연도 3개 + 평균, 오른쪽 위 「(단위: {단위})」, 비율 행은 계산식 괄호 · 재무 현황 · [R-0011]
- **역할별 투입 인원 줄** — 「정규 투입 총 {수치}명」 + PM · 기획 · 디자인 · 퍼블리싱 · 개발 · 검증 칸마다 {수치}명 · 범위 · 사례 · [R-0012]
- **비중 큰 숫자 + 대비 작은 합계** — 「00% {항목} 비중」 + 「{대비 항목}은 다 합쳐 00%」 + 기준 라벨 「{분석 도구} {기간} · 실사용자 기준」 · 현행 이용 실태 · [R-0007]
- **1인당 횟수 · 배수** — 「00회 {대상} 1인당 조회」 「0.0배 {비교 기준} 대비」 — 횟수 · 배수를 기준 문구와 함께 · 이용 행태 진단 · [R-0007]
- **0건 부재 강조** — 「0건」 큰 숫자 + 「{발생 건수}는 있는데 성과로 잡히는 {항목}이 하나도 없는 상태」 — 없는 것을 숫자로 · 측정 공백 · [R-0007]
- **이용 규모 첫 줄** — 「{수치}만 {이용자}가 쓰는 {플랫폼}」을 배경 · 이슈 첫 줄에 두어 과제의 무게 제시 · 제안 배경 · [R-0013]
- **분수 표기 목표 + 도달 시점** — 「00% · {N}건 중 {M}건」 큰 숫자 + 「착수 {기간} 내 도달 목표」 · AX 효과 · [R-0005]
- **검증 전 목표 타일** — 큰 목표 숫자 위 「목표 후보 · 검증 전」 라벨, 아래 「적용 범위 · 정의」 · 「검증할 기준」 두 칸 · 계약 전 SLA 제시 · [R-0006]
- **분자 / 분모 산식표** — 지표 | 「{충족 건} / {대상 건}」 | 주기 · 데이터 원천, 공정 지표(처리율 · 처리 시간 · 재작업)와 성과 지표(리드타임 · 반려 · 전환율) 두 묶음, 공통 규칙에 「대상이 없으면 '해당 없음'」 · KPI 정의 · [R-0005, R-0006]
- **수치 출처 경계 각주** — 다른 고객 실증 수치 옆 「※ 다른 고객 실증 데이터이며 이번 사업 효과를 뜻하지 않음」 · 레퍼런스 · [R-0006]
- **전제 수치 각주** — 「※ 최소 {수치}{단위} 이상 {데이터 종류} 필요」 — 효과 주장 대신 성립 조건을 수치로 · AI 도입 조건 · [R-0014]
- **레퍼런스 성과 2수치 + 정성 효과** — 「참여 00여 건 · 재생 00여 회 · 효과 {정성 라벨}」 + 운영 기간 「0주」 · 레퍼런스 · [R-0007]
- **해상도 · 브라우저 점유율 표** — 기준 해상도 3단(PC · 태블릿 · 모바일) 큰 숫자 + 기기별 점유율 목록, 플랫폼 × 브라우저 표 마지막 열 「커버리지 00%」 강조, 미지원은 ※ 각주(이유 + 접속 가능 여부) · 반응형 · 호환 범위 · [R-0013]
- **발생 · 미처리 · 합계 3열 집계** — 지역 · 팀 행 × 「발생 · 미처리 · 합계」 열, 새로 더한 합계 열 강조 · 관제 · 현황 화면 · [R-0009]
- **미확인 건수 배너 · 지표 이름 나열** — 「확인하지 않은 알림 {N}건」 숫자만 굵게, 평가지표 화면은 「ex) 만족도, 신속도, 입력률」처럼 이름만 나열 · 홈 · 통계 화면 · [R-0009]
- **대괄호 속성 수치 카드** — 카드마다 「[담당 범위] {범위}」 「[근무 요일] {요일}」 「[일일 처리 건수] 00건」을 같은 순서로 반복 · 배정 · 운영 체계 · [R-0014]

## 2. 단계 · 전후

- **단계별 단축률 타일** — 직무 단계마다(기획 · 디자인 · 개발) 「{단계} {수치}% 단계 단축」 큰 % + 아래 도구 체인 흐름 · 단계마다 같은 판형으로 장 1장씩 · AX 적용 · [R-0001]
- **등식 결과 강조** — 「BEFORE … vs AFTER … = 연간 합계 {수치}」 결과 상자만 큰 숫자 · 합계 단위를 결과 옆에 · 효과 정량화 · [R-0001]
- **배분 · 인원 합산 등식** — 「총 00MM/월 = 영역 A 0.0 + 영역 B 0.0 + 영역 C 0.0」 · 「PM {N} + 클러스터 A {N} + B {N} = {합계}명」 — 합계 타일 아래 덧셈으로 배분 · 인력 배분 · 조직 구성 · [R-0005, R-0006]
- **표본 건수 → 3분류 비율 바** — 「{기간} 표본 {N}건」 → 자동화 · 작업 · 검토 3분류 건수와 00% 가로 바, 옆 유형별 건수, 각주에 산출 근거(기간 · 중복 제거) · 자동화 범위 산정 · [R-0005]
- **단계 수 축소 전후** — 「기존 {N}단계 → {N}단계」 캡션 두 줄(「기존 {프로세스}: 총 {N}단계 화면 / 변경: 총 {N}단계 · 통합 · 중복 삭제」) · 프로세스 · 설정 기능 개선 · [R-0011, R-0013]
- **짧은 시간 · 긴 시간 짝** — 「00초 {첫 화면}」 vs 「0분 00초 {자료 페이지}」 — 같은 단위 시간 둘로 어디서 머물고 어디서 지나치는지 · 이슈 카드 · [R-0007]
- **연도 2묶음 × 4지표 막대 + 해석 2줄** — 과제 수 · 피드백 · QA · 지연 4지표를 연도 2개로 묶은 막대, 아래 「과제 수 증가 / 피드백 · 지연 감소」 · 품질 성과 증명 · [R-0012]
- **구간 문턱 3단** — 「≥00% → {행동} / 00–00% → {행동} / <00% → 중단」 — 부등호와 구간, 기준 지표 이름을 앞에 · PoC 판단 기준 · [R-0014]
- **등급 칩 · 3단 심각도** — 지침 번호 + 항목 + 「미흡 · 심각」 등급 칩 + 위반 내용 한 줄 카드 2×2, 판정 결과에 「심각도(경 / 중 / 상)」 괄호 · 접근성 진단 · 판정 기능 · [R-0013, R-0014]
- **수치 없는 방향 태그** — 기준선이 없을 때 「# {지표} 감소」 「# {지표} 단축」처럼 방향만 · 사례 카드 · [R-0005]
- **버전 전환 목록** — 「{기술 요소} {현 버전} → {목표 버전}」 3줄, 옆 기대 효과 3개 · 기술 업그레이드 · [R-0010]

## 3. 기간 · 시간

- **기간 강조** — 「{시작일} ~ {종료일}」 날짜 범위 + 「불과 {N}주」, 또는 「안정화 포함 약 {N}개월」처럼 괄호로 포함 조건을 붙이고 짧음 강조 · 전환 · 인수인계 · 일정 리스크 · [R-0001, R-0009, R-0010, R-0013]
- **등급별 시간 목표** — 등급마다 「{N}분 내 임시조치 / {N}분 내 근본복구」 두 숫자를 한 칸에 · 위 등급일수록 짧게 · 장애 대응 · [R-0001]
- **상대 월 간트 머리** — 절대 날짜 대신 「M · M+1 … M+{N}」, 착수 시점만 「{월} 착수」로 한 번 · 추진 일정 · [R-0009]
- **기간 총량 + 단계 구분 한 줄** — 「안정화 포함 총 {N}개월, {분석 · 설계 · 개발 · 테스트} 단계로 구분」 · 일정 장 리드 · [R-0010]
- **D-n 카운트다운 이정표** — D-{n} ▶ … ▶ D-day 가로, 칸마다 할 일 한 단어 · 교체 절차 「{N}주 전 보고 → 승인 → 병행 → 교체일」, 주차 로드맵(1 · 2 · 3주차 → 개시)도 같은 계열 · 인수 · 인력 교체 · [R-0005, R-0006]
- **검증 시점 4점** — 첫날 · 90일 · 6개월 · 1년 마일스톤 카드, 시점마다 확인할 상태 한 줄 · 연간 일정 · [R-0006]
- **창립 → 기념 연도 큰 숫자** — 「{창립 연도} → {기념 연도}」 사이 주년 숫자 크게 + 「{다음}을 여는 기반」 · 배경 · [R-0007]
- **총 투입 머리 표기** — 표 머리 「총 00 M/M · 착수일로부터 0개월」, 역할 행 × 월 열 + 월별 합계 행 · 투입 인력 · [R-0007]
- **기간 범위 + 소요 개월 별도 열** — 실적표에 「{시작 연월} ~ {종료 연월}」과 「{N}개월」을 다른 열로, 진행 중이면 「진행 중」 · 사례는 「{구분 칩} {사업} / {연도} ~ {연도}」 배지 · 실적표 · [R-0012, R-0015]
- **연혁 3기 구분** — 기간을 3기로 나누고 기마다 두 단어 이름 + 연도 범위 라벨, 아래 연도별 실적 · 회사 연혁 · [R-0011]
- **화면 속 시간 표기 쌍** — 상태 카드에 「{시작} 일시: {시각}」 + 「예상 작업 시간: 약 00분」 · 와이어 상태 카드 · [R-0014]
- **무상 범위 횟수 약속** — 「{텍스트 · 단순 이미지} 수정 월 {N}회 무상」 — 범위 + 주기 + 횟수 한 줄 · 사후 지원 · [R-0013]
