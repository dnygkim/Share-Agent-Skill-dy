# 정합성 체크리스트 (qa 핵심 도구)

이 하네스의 존재 이유. 합계 1개를 바꾸면 문서 여러 곳이 함께 바뀌어야 하는데, 수동 작업 시 누락이 반복됐다(시운전에서도 phantom +4.0·29.0/33.0 불일치 적발). qa는 아래를 기계적으로 교차검증한다.

## 정본 규칙 (a)-(h) — `report-spec.md` §5
하나라도 어긋나면 **불합격**:
```
(a) 영역표 num column 합 = 제작 소계
(b) 제작 소계 + PM/기획 소계 = 총 공수
(c) 영역표 디/퍼/개 합 = 월별표 직군 소계 = hero "총공수" 분해 = 핵심요약 인력합
(d) 월별표: 각 역할 행 = 월셀 합 / 각 월 = 직군 소계 합 / 월 합계 = 총 공수
(e) 개월수: 월별 colspan = 매트릭스 단계 = WBS 블록수 = 간트 totalWeeks/4 = hero "기간" = footer
(f) 간트 totalWeeks = 개월수×4, W 컬럼수 = totalWeeks, 모든 task end ≤ totalWeeks
(g) 팔레트: 이전 브랜드 hex 잔존 = 0 (예: 코스모진 레드 #c8102e/#8a0a1f)
(h) 변경 후 옛 총량/개월수 문자열 잔존 = 0 (예: 47.0→57.0 시 "47.0" 0건)
```

## 수치 등장 위치 맵 (같은 값이 반복 → 전부 일치)
총 M/M · 인원 · 기간 · 영역별 분해는 아래에 반복된다:
- 히어로 카드 "총 공수" `.value` + `.sub`(영역별 분해)
- 영역별 요약표(표1) "총 공수" 행
- 월별표(표2) 총계
- 핵심요약 카드(표6) "투입 인력 (총 N명, X M/M)"
- 푸터 "총 X M/M · N개월 · N명"
- 각 섹션 lead/서술문 (예: "5개월 · 8명 · 32.0 M/M")
- 간트 totalWeeks(JS) / footer 개월수

## 검증 방법
- **산술(a~f)**: `scripts/check_consistency.py`로 HTML 표를 파싱·합산해 자동 대조. 간트는 JS `tasks[]`/`totalWeeks` 파싱.
- **잔존(g,h)**: 단순 문자열 grep — 이전 브랜드 hex / 옛 총량·개월수 문자열이 0건인지. **수정 작업 후 반드시 실행**(in-place 수정의 누락을 잡는 핵심).
- **표기(8장)**: 물결표(~) 미사용(HTML 본문 `~5스타일` 류는 예외), 빈 셀 `.num zero">-`, 버전 문자열 일관.
- 발견은 위치(섹션·라인) · 현재값 · 기대값 · 근거(어느 규칙 위반)로 보고. 상충 데이터는 임의 삭제 금지(출처 병기).
